Upload

파일 선택·드래그 앤 드롭·업로드 목록·이미지 카드·아바타 업로드 UI를 제공합니다. upload_input은 시각적으로 숨기고 label.upload_trigger · label.upload_dropzone으로 트리거합니다. 버튼형 트리거는 button 대신 span.btn으로 스킨을 적용합니다.

버튼 업로드

label.upload_trigger 안에 span.btn으로 버튼 스킨을 적용합니다. button 요소는 label 안에 넣지 않습니다.

PNG, JPG · 최대 5MB

  </label>
</div>

폼 필드

form_field와 조합해 레이블·힌트·오류 메시지를 표시합니다.

제출 전 파일명을 확인해 주세요.

첨부파일은 필수입니다.

클래스 · 속성

Nuxt와 Next 컴포넌트가 공통으로 렌더하는 OOCSS 클래스와 네이티브 파일 입력 속성입니다. HTML에서는 업로드 유형과 파일 상태에 맞게 직접 조합합니다.

클래스 · 속성 설명
uploadUpload 루트
upload_sm · upload_lg · upload_fit드롭존 크기와 최대 너비 변형
upload_trigger · upload_input버튼형 label 트리거와 시각적으로 숨긴 file input
upload_dropzone · upload_dropzone-icon클릭·드래그 파일 선택 영역과 아이콘
upload_dropzone-title · upload_dropzone-desc드롭존 제목과 파일 제한 설명
upload_hint허용 형식·용량 등 업로드 보조 설명
upload_list · upload_item파일 목록과 개별 파일 항목
upload_item-icon · upload_item-body · upload_item-action파일 아이콘·정보 영역·취소 또는 삭제 액션
upload_item-name · upload_item-meta파일명과 용량·진행·오류 정보
upload_progress · upload_progress-bar업로드 진행률 트랙과 값 막대
upload_cards · upload_card · upload_card-image이미지 카드 그리드, 카드와 미리보기 이미지
upload_card-trigger · upload_card-actions사진 추가 트리거와 카드 호버 액션
upload_avatar · upload_avatar-overlay아바타 파일 선택 트리거와 호버 오버레이
is-dragover · is-uploading · is-done · is-error · is-disabled드래그 오버·진행·완료·오류·비활성 상태
type="file" · multiple · accept · disabled파일 입력 유형, 다중 선택, 허용 형식과 비활성 상태
aria-invalid · aria-describedby오류 상태와 피드백 메시지 연결

aria-valuenow · aria-valuemin · aria-valuemax현재·최소·최대 업로드 진행률

data-ripple="false" · data-no-ripple해당 트리거 또는 Upload 하위 전체의 클릭 파장 비활성
change · dragenter · dragover · dragleave · drop파일 선택과 드래그 앤 드롭을 처리하는 네이티브 이벤트
