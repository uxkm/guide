Snackbar

작업 결과나 짧은 상태 메시지를 일시적으로 전달하는 컴포넌트입니다. 8개 화면 위치, 상태 색상, 액션, 자동 닫기와 모션을 지원합니다.

기본

info · success · warning · error 의미 색상으로 짧은 피드백을 전달합니다.

새로운 업데이트가 있습니다.
변경 사항을 저장했습니다.
세션이 곧 만료됩니다.
저장하지 못했습니다.

호출 · 닫기 효과

Fade는 제자리에서 투명도를 전환하고, Slide는 표시 위치에서 가장 가까운 화면 가장자리 방향으로 호출·퇴장합니다. None은 전환 없이 즉시 표시하고 닫습니다.

<!-- Fade 호출 -->

<button type="button" class="btn btn_outline" data-snackbar-trigger="bottom-center" data-motion="fade" data-message="Fade 효과">
  <span class="btn_label">Fade 호출</span>
</button>

<!-- Slide 호출 -->

<button type="button" class="btn btn_outline" data-snackbar-trigger="middle-end" data-motion="slide" data-message="우측 Slide 효과">

</button>

자동 닫기

data-duration을 밀리초로 지정하면 자동으로 닫힙니다. Snackbar를 호버하거나 내부 요소에 포커스하면 타이머가 일시정지됩니다.

<!-- 4초 Snackbar 호출 -->

<button type="button" class="btn btn_filled color_success" data-snackbar-trigger="bottom-center" data-color="success" data-duration="4000" data-action="false" data-message="4초 후 자동으로 닫힙니다.">
  <span class="btn_label">4초 Snackbar 호출</span>
</button>

<!-- 유지 Snackbar 호출 -->

<button type="button" class="btn btn_outline" data-snackbar-trigger="bottom-center" data-duration="0" data-action="false" data-message="자동 닫기가 비활성화되어 있습니다.">
  <span class="btn_label">유지 Snackbar 호출</span>
</button>

접근성

  • 일반적인 작업 결과는 role="status"로 정중하게 알리고, 즉시 확인해야 하는 오류에만 role="alert"를 사용합니다.
  • Snackbar가 나타나도 포커스를 강제로 이동하지 않습니다.
  • 자동 닫기를 사용할 때는 내용을 읽고 액션을 수행할 충분한 시간을 제공합니다. 호버·내부 포커스 중에는 타이머를 멈춥니다.
  • 닫기 가능한 Snackbar는 내부 포커스 상태에서 Esc로도 닫을 수 있어야 합니다.
  • 아이콘은 장식 요소로 숨기고, 상태를 색상이나 아이콘에만 의존하지 않도록 메시지를 명확히 작성합니다.
  • prefers-reduced-motion 설정에서는 모션 시간을 최소화합니다.

마크업

일반 상태는 role="status"를 사용하고, 즉시 확인해야 하는 오류에만 role="alert"를 사용합니다.

<div class="snackbar color_success snackbar_motion-fade is-open"
  role="status" aria-live="polite" aria-atomic="true">
  <div class="snackbar_message">변경 사항을 저장했습니다.</div>
  <button class="btn btn_ghost snackbar_close" aria-label="알림 닫기">…</button>
</div>
