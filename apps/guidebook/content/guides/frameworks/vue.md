Vue 구현은 선언형 템플릿과 반응형 상태로 HTML 기준과 같은 DOM·접근성 계약을 유지합니다. Nuxt는 Vue 컴포넌트를 재사용합니다. 공통 계약과 완료 기준은 [프레임워크 구현](../index.html)에서 확인합니다.

## 이 문서에서 다룰 내용

- props와 emits 계약
- `v-model`과 slot 구조
- Nuxt에서 Vue 구현을 재사용하는 방식

문법 예제와 컴포넌트별 사용법은 이 페이지에 이어서 추가합니다.
