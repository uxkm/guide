React

React에서 UXKM 컴포넌트를 사용하는 props, 이벤트, children 문법을 정리합니다.

React 구현은 props와 상태 모델로 HTML 기준과 같은 DOM·접근성 계약을 유지합니다. Next.js는 React 컴포넌트를 재사용합니다. 공통 계약과 완료 기준은 프레임워크 구현에서 확인합니다.

이 문서에서 다룰 내용

  • props와 이벤트 계약
  • controlled·uncontrolled 정책과 ref 전달
  • Next.js에서 React 구현을 재사용하는 방식

문법 예제와 컴포넌트별 사용법은 이 페이지에 이어서 추가합니다.
