## 호환 원칙

- 공통 CSS는 `packages/styles`의 단일 원본에서 생성합니다.
- Nuxt와 Next.js는 각각 Vue와 React 컴포넌트를 재사용합니다.
- WebSquare는 HTML 예제를 XML 호환 마크업으로 변환하며, 복잡한 컴포넌트는 전용 예제로 대체할 수 있습니다.
- Container, Grid, Flex, Divider, Space, Button, Typography, Icon, Link는 WebSquare 컴포넌트·이벤트·리소스 특성을 반영한 전용 XML 예제를 제공합니다.
- 프레임워크별 문법이 달라도 API 의미와 사용자 동작은 일치시킵니다.
- 라우팅과 이미지 최적화처럼 프레임워크가 소유해야 하는 기능만 전용 컴포넌트로 제공합니다.
- 변경 시 일곱 구현 코드와 Storybook 문서를 같은 작업 범위에서 확인합니다.

이 표는 저장소 구조 기준의 지원 범위입니다. 특정 컴포넌트의 사용법과 제한은 각 컴포넌트 문서를 참고합니다.
