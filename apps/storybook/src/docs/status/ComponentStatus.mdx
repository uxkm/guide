## 완료 기준

컴포넌트는 아래 항목을 모두 충족할 때 공통 제공 상태로 봅니다.

- HTML, Gulp, Vue, React 구현 파일 존재
- Vue와 React 테스트 존재
- 공통 SCSS 및 스타일 빌드 연결
- Storybook Preview, 프레임워크 예제, API 문서 제공
- 키보드와 접근성 상태 검수

저장소의 `pnpm validate:components` 검사는 52개 컴포넌트의 필수 파일과 중앙 Storybook 구조를 확인합니다. 개별 변경의 품질은 관련 테스트와 정적 빌드도 함께 통과해야 합니다.
