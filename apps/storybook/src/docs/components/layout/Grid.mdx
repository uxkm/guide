# Grid

12열 CSS Grid 기반 레이아웃 시스템입니다. 대부분의 배치는 부모 Grid에서 제어하고, 혼합 레이아웃만 GridCol로 개별 span을 지정합니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/grid`, `@uxkm/react/grid`로 제공합니다. Nuxt와 Next.js는 같은 구현을 재사용합니다.

WebSquare는 별도 런타임 컴포넌트 없이 `w2:group`에 동일한 `grid` 클래스를 적용합니다. 아래 코드 탭에서 WebSquare XML을 함께 확인할 수 있습니다.

## 사용 기준

- 행과 열을 함께 제어하는 2차원 배치에는 Grid를 사용합니다. 한 방향 정렬이나 콘텐츠 크기 중심 배치는 Flex, 단순한 항목 간격은 Space가 더 적합합니다.
- `cols`, `ratio`, `autoFit`, `autoFill`, `equalColumns`는 모두 열 트랙을 정의하는 모드입니다. 한 Grid에서는 의도한 모드 하나만 선택합니다.
- 모든 자식의 폭이 같으면 `itemSpan`, 자식마다 폭이 다르면 GridCol의 `span`을 사용합니다.
- 반응형 값은 기본 → md → lg 순서의 mobile-first 방식으로 덮어씁니다.

## WebSquare 사용

공통 스타일을 로드한 뒤 Grid와 GridCol을 각각 중첩된 `w2:group`으로 작성합니다. Grid에는 `grid`와 부모 변형 클래스를, GridCol에는 `grid_col-span-*` 클래스를 지정합니다. `header`, `aside`, `main`, `footer` 같은 문서 구조는 `tagname`으로 유지합니다. 레이아웃만 담당하므로 `scwin` 이벤트와 DataList 바인딩은 필요하지 않습니다.

## 접근성

- CSS Grid가 시각적 배치만 바꾸도록 콘텐츠를 읽고 조작해야 하는 순서대로 DOM에 작성합니다.
- 페이지 랜드마크에는 의미에 맞는 `as` 또는 WebSquare `tagname`을 사용하고, 한 페이지의 `main`은 하나만 둡니다.
- 작은 화면에서도 콘텐츠가 잘리거나 가로 스크롤을 강제하지 않는지 확인합니다. 긴 텍스트와 폼 컨트롤을 포함한 실제 콘텐츠로 반응형 구간을 검증합니다.
- Grid와 GridCol 자체에는 불필요한 ARIA role을 추가하지 않습니다. 제목, 목록, 내비게이션 같은 의미는 내부 콘텐츠의 시맨틱 요소로 제공합니다.
