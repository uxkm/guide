# Grid

12열 CSS Grid 기반 레이아웃 시스템입니다. 대부분의 배치는 부모 Grid에서 제어하고, 혼합 레이아웃만 GridCol로 개별 span을 지정합니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/grid`, `@uxkm/react/grid`로 제공합니다. Nuxt와 Next.js는 같은 구현을 재사용합니다.
