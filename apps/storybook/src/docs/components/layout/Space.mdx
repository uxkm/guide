# Space

자식 요소 사이 간격을 일관되게 맞추는 flex 기반 레이아웃 컴포넌트입니다. 간격·방향·정렬·줄바꿈을 조합합니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/space`, `@uxkm/react/space`로 제공합니다. Nuxt와 Next.js는 같은 구현을 재사용합니다.
