# Flex

CSS Flexbox 기반으로 방향·간격·정렬·반응형 항목 크기를 제어하는 레이아웃 컴포넌트입니다. 혼합 배치는 FlexItem으로 개별 자식을 제어합니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/flex`, `@uxkm/react/flex`로 제공합니다. Nuxt와 Next.js는 같은 구현을 재사용합니다.
