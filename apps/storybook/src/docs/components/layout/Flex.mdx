# Flex

CSS Flexbox 기반으로 방향·간격·정렬·반응형 항목 크기를 제어하는 레이아웃 컴포넌트입니다. 혼합 배치는 FlexItem으로 개별 자식을 제어합니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/flex`, `@uxkm/react/flex`로 제공합니다. Nuxt와 Next.js는 같은 구현을 재사용합니다.

WebSquare는 별도 런타임 컴포넌트 없이 `w2:group`에 동일한 `flex` 클래스를 적용합니다. 아래 코드 탭에서 WebSquare XML을 함께 확인할 수 있습니다.

## 사용 기준

- 한 방향의 정렬·분배 또는 콘텐츠 크기 중심 배치에는 Flex를 사용합니다. 행과 열을 함께 제어하는 2차원 배치는 Grid, 단순한 항목 간격은 Space가 더 적합합니다.
- `cols`, `ratio`, `itemSpan`, `equal`, `autoFit`은 항목 너비를 정의하는 모드입니다. 한 Flex에서는 의도한 모드 하나를 우선 사용하고, 예외 항목만 FlexItem으로 조정합니다.
- FlexItem의 개별 `span`으로 여러 행을 구성할 때는 부모 Flex에 `wrap`을 지정합니다.
- 반응형 값은 기본 → md → lg 순서의 mobile-first 방식으로 덮어씁니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 `Flex`와 `FlexItem` 컴포넌트 자체의 구현입니다. React와 Vue는 전달받은 prop을 검증해 공통 CSS 클래스로 변환하고, HTML은 같은 클래스를 마크업에 직접 적용합니다. Gulp는 `flex` · `flexItem` Nunjucks macro와 `{% call %}`로 같은 계약을 재사용합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 그대로 재사용합니다.

- `range`는 항목 수, span과 표시 순서를 1~12 범위로 제한합니다.
- `direction`·`directionMd`·`directionLg`는 구간별 배치 방향을, `wrap`은 여러 줄 배치를 제어합니다.
- `cols`·`ratio`·`itemSpan`은 부모에서 자식 너비를 일괄 제어하는 방식입니다.
- `gap`·`align`·`justify`는 허용된 문자열만 클래스에 반영합니다.
- `equal`·`autoFit`은 동일 너비 확장과 최소 너비 기반 자동 배치 클래스로 변환됩니다.
- FlexItem은 자식마다 다른 `span`, `grow`, `fit`, `align`, `order`가 필요한 경우에 사용합니다.
- `as`, 사용자 정의 클래스와 나머지 속성, React의 `children` 또는 Vue의 기본 slot은 루트 요소에 전달됩니다.

## WebSquare 사용

공통 스타일을 로드한 뒤 Flex와 FlexItem을 각각 중첩된 `w2:group`으로 작성합니다. Flex에는 `flex flex_row`와 부모 변형 클래스를, FlexItem에는 `flex_item-span-*`, `flex_grow`, `flex_fit` 같은 자식 클래스를 지정합니다. 문서 구조는 `tagname`으로 유지하며, 레이아웃만 담당하므로 `scwin` 이벤트와 DataList 바인딩은 필요하지 않습니다.

## 접근성

- 시각적 배치와 관계없이 콘텐츠를 읽고 키보드로 조작해야 하는 순서대로 DOM에 작성합니다.
- FlexItem의 `order` 또는 `flex_order-*`는 화면 표시 순서만 변경합니다. 의미 있는 콘텐츠나 포커스 가능한 요소의 순서를 바꾸는 용도로 사용하지 않습니다.
- 페이지 랜드마크에는 의미에 맞는 `as` 또는 WebSquare `tagname`을 사용하고, 한 페이지의 `main`은 하나만 둡니다.
- 작은 화면과 텍스트 확대 환경에서 항목이 겹치거나 잘리지 않는지 확인하고, 필요하면 `wrap` 또는 세로 방향으로 전환합니다.
- Flex와 FlexItem 자체에는 불필요한 ARIA role을 추가하지 않습니다. 목록·내비게이션 등의 의미는 내부 콘텐츠의 시맨틱 요소로 제공합니다.
