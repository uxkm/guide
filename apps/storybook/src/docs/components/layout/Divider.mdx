# Divider

콘텐츠를 시각적으로 구분하는 구분선입니다. 단순 선·점선·텍스트 레이블·세로 구분을 공통 클래스로 조합합니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/divider`, `@uxkm/react/divider`로 제공합니다. Nuxt와 Next.js는 같은 구현을 재사용합니다.

WebSquare는 Divider의 의미에 따라 XHTML `hr`·`span` 또는 `w2:group`을 사용합니다. 아래 코드 탭에서 각 유형에 맞는 WebSquare XML을 확인할 수 있습니다.

## 사용 기준

- 콘텐츠 주제가 전환되는 의미 있는 수평 구분에는 레이블 없는 Divider를 사용합니다. React와 Vue에서는 자동으로 `hr`가 선택됩니다.
- 단순한 여백 확보가 목적이면 Divider 대신 spacing token이나 Space를 사용합니다.
- 레이블형 Divider는 시각적인 구분과 짧은 보조 문구에 사용합니다. 실제 섹션 제목이라면 별도의 `h2`·`h3` 등 제목 요소를 함께 제공합니다.
- 세로 Divider는 버튼이나 짧은 텍스트가 한 행에 배치된 경우에만 장식용으로 사용합니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 `Divider` 컴포넌트 자체의 구현입니다. React와 Vue는 전달받은 prop을 검증해 공통 CSS 클래스로 변환하고, HTML과 Gulp는 같은 클래스를 마크업에 직접 적용합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 그대로 재사용합니다.

- `tag`가 `auto`이면 레이블 없는 선은 `hr`, 레이블형은 `div`, 세로선은 `span`으로 루트를 선택합니다.
- `as`는 `tag`보다 우선하며, 허용된 `tag` 값만 루트 요소 선택에 반영됩니다.
- `vertical`·`dashed`·`plain`·`orient`는 검증된 값만 `divider_*` 클래스로 변환됩니다.
- `label`과 React `children`(또는 Vue 기본 slot)은 레이블 콘텐츠로 사용되며, `hr` 루트에는 자식을 두지 않습니다.
- 세로 Divider는 장식이므로 `aria-hidden="true"`를 적용합니다.
- 사용자 정의 클래스와 나머지 속성은 루트 요소에 전달됩니다.

## WebSquare 사용

레이블 없는 수평선은 `<hr class="divider" />`로 의미를 유지합니다. 레이블형은 `divider` 클래스를 가진 `w2:group` 안에 `w2:textbox`를 배치하고, 세로선은 `aria-hidden="true"`인 XHTML `span`에 `divider_vertical` 클래스를 적용합니다. 상태가 없는 시각적 구분 요소이므로 `scwin` 이벤트와 DataList 바인딩은 필요하지 않습니다.

## 접근성

- 의미 있는 수평 구분선은 `hr`를 유지합니다. 단순 장식선이라면 보조 기술에 중복 정보를 주지 않도록 사용 자체를 줄이거나 `aria-hidden="true"`를 적용합니다.
- 세로 Divider는 콘텐츠 의미를 전달하지 않으므로 항상 `aria-hidden="true"`로 접근성 트리에서 제외합니다.
- 레이블형 Divider의 텍스트만으로 문서 제목 계층을 대신하지 않습니다. 섹션 구조가 필요하면 실제 제목 요소를 사용합니다.
- `tag` 또는 `as`로 루트 요소를 강제할 때는 수평 구분선의 의미가 사라지지 않는지 확인합니다.
