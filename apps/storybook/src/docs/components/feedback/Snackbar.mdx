## 접근성

일반적인 작업 결과는 `role="status"`로 알리고 즉시 확인해야 하는 오류에만 `role="alert"`를 사용합니다. 아이콘은 장식 요소로 숨기며, 자동 닫기를 사용할 때는 내용을 읽고 액션을 수행할 충분한 시간을 제공해야 합니다.
