# Modal

중요한 정보 확인이나 사용자 입력이 필요한 작업을 전체 브라우저 위의 대화상자로 제공합니다.

## 기본

백드롭, 닫기 버튼, Esc 키로 닫을 수 있으며 닫은 뒤 트리거로 포커스가 돌아갑니다.

## 접근성

Modal은 `role="dialog"`, `aria-modal="true"`, 제목 연결을 제공하고 열릴 때 내부로 포커스를 이동합니다. Tab 키는 Modal 안에서 순환하며 Esc로 닫은 뒤 기존 포커스를 복원합니다.
