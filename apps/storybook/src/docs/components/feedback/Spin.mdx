# Spin

작업이 진행 중임을 회전 표시기 또는 콘텐츠 오버레이로 안내합니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

Spin은 `role="status"`, `aria-live="polite"`, `aria-busy="true"`를 제공하며 장식용 표시기는 보조 기술에서 제외합니다. 콘텐츠 위 오버레이는 `SpinWrap`으로 제공합니다.

WebSquare는 표시기를 `w2:group.spin`, 오버레이 래퍼를 `w2:group.spin_wrap`으로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Spin과 SpinWrap의 실제 원본 구현입니다. React와 Vue는 크기, 색상, 설명 문구, 인라인·블록·오버레이 배치를 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `tip`은 표시기 아래 설명 문구를 제공합니다.
- `inline`·`block`·`overlay`로 배치 방식을 전환합니다.
- `SpinWrap`은 대상 콘텐츠 위에 로딩 오버레이를 올립니다.
- `blur`는 오버레이 아래 콘텐츠에 블러를 적용합니다.

## WebSquare 사용

`w2:group.spin`에 `role="status"`와 `aria-busy="true"`를 적용하고 표시기는 `spin_indicator`로 구성합니다. 컨테이너 오버레이는 `spin_wrap is-loading` 안에 콘텐츠와 `spin_overlay`를 함께 둡니다.

크기·색상은 `spin_sm`·`spin_lg`와 `color_*` 클래스로 표현합니다.
