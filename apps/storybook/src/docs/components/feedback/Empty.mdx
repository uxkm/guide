# Empty

데이터나 검색 결과가 없을 때 현재 상태와 다음 행동을 안내합니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

Empty 루트는 `role="status"`로 상태를 전달하고 장식용 이미지는 `aria-hidden="true"`로 보조 기술에서 제외합니다. 액션 버튼의 목적은 구체적인 문구로 제공합니다.

WebSquare는 빈 상태를 `w2:group.empty`, 설명·이미지를 `w2:textbox`, 후속 액션을 `xf:trigger`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Empty 자체의 실제 원본 구현입니다. React와 Vue는 설명, 아이콘, 액션 푸터, 크기와 간단형·블록 변형을 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `simple`은 아이콘 없이 설명만 표시합니다.
- `block`은 컨테이너 전체 너비에 맞춥니다.
- `icon`/`#icon`과 `footer`/`#footer`로 커스텀 슬롯을 제공합니다.
- 지원하지 않는 크기는 `md`로 정규화합니다.

## WebSquare 사용

`w2:group.empty`에 `role="status"`를 적용하고 `empty_desc`로 안내 문구를 전달합니다. 후속 액션은 `empty_footer` 안의 `xf:trigger`로 구성합니다.

크기·간단형·블록은 `empty_sm`·`empty_lg`·`empty_simple`·`empty_block` 클래스로 표현합니다.
