# Skeleton

콘텐츠를 불러오는 동안 실제 레이아웃과 유사한 플레이스홀더를 표시합니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

로딩 영역은 `role="status"`, `aria-live="polite"`, `aria-busy="true"`를 제공하고 장식용 플레이스홀더는 보조 기술에서 제외합니다. `prefers-reduced-motion` 환경에서는 쉬머 애니메이션이 자동으로 비활성화됩니다.

WebSquare는 플레이스홀더 그룹을 `w2:group.skeleton_group`, 개별 형태를 `w2:textbox.skeleton_*`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Skeleton 자체의 실제 원본 구현입니다. React와 Vue는 아바타·문단·원형·카드형 플레이스홀더와 쉬머 활성 여부를 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `paragraph`로 본문 줄 수를 지정합니다.
- `avatar`·`round`로 원형 플레이스홀더를 조합합니다.
- `active={false}` 또는 `skeleton_static`으로 쉬머를 끕니다.
- children/슬롯으로 카드형 커스텀 구성을 지원합니다.

## WebSquare 사용

`w2:group.skeleton_group`에 `role="status"`와 `aria-busy="true"`를 적용하고 `skeleton_text`·`skeleton_title`·`skeleton_circle`로 형태를 조합합니다. 정적 표시는 `skeleton_static` 클래스를 사용합니다.
