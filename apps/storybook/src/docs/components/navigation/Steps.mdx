# Steps

여러 단계로 구성된 작업의 완료, 현재, 대기 및 오류 상태를 순서대로 표시합니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

현재 단계는 `aria-current="step"`으로 표시합니다. 탐색형에서 대기 단계는 비활성화하며 완료된 단계만 이전 단계로 이동할 수 있습니다. 애니메이션은 `prefers-reduced-motion` 환경에서 제거됩니다.

WebSquare는 단계 목록을 `w2:group.steps`, 각 단계를 `w2:group.steps_item`, 마커·제목을 `w2:textbox`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Steps와 StepsItem의 실제 원본 구현입니다. React와 Vue는 가로·세로, 도트·간단형, 아이콘, 탐색 가능과 오류 상태를 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `status`는 done·current·wait·error를 `is-*` 클래스로 표현합니다.
- 현재 단계는 `aria-current="step"`을 사용합니다.
- `navigable`은 완료된 단계만 클릭으로 이동합니다.

## WebSquare 사용

`w2:group.steps` 안에 `steps_item`을 배치하고 `is-done`·`is-current`·`is-wait`·`is-error`로 상태를 표시합니다. 현재 단계는 `aria-current="step"`을 적용합니다.
