# Badge

상태, 분류, 개수를 짧게 표시하는 컴포넌트입니다. 텍스트·상태 점·카운트·다른 요소 위의 겹침 배지를 지원합니다.

Vue와 React 구현은 각각 `@uxkm/vue/badge`, `@uxkm/react/badge`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

WebSquare는 `w2:textbox`에 공통 Badge 클래스를 적용하고, 다른 컨트롤 위에 겹칠 때는 `w2:group.badge_wrap`으로 기준 요소와 Badge를 감쌉니다. 각 WebSquare 탭의 코드는 화면 XML 루트에서 `w2`와 `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 `Badge`와 `BadgeWrap` 컴포넌트 자체의 구현입니다. React와 Vue는 prop을 공통 클래스와 접근성 속성으로 변환하고, HTML과 Gulp는 같은 구조와 클래스를 마크업에 직접 적용합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 그대로 재사용합니다.

- `color`·`size`는 `color_*`·`badge_*` 클래스로 변환되며 `md`는 기본 크기입니다.
- `dot`은 텍스트 앞 상태 점, `count`는 안정적인 숫자 폭, `dotOnly`는 텍스트 없는 상태 표시를 만듭니다.
- `dotOnly`는 `role="status"`를 사용하고 `ariaLabel`로 상태 의미를 제공합니다.
- `BadgeWrap`은 기준 요소와 겹침 Badge를 같은 좌표 컨텍스트에 배치합니다.

## WebSquare 사용

일반·상태 점·카운트 Badge는 `w2:textbox`의 `label`과 `badge`, `badge_dot`, `badge_count`, `color_*` 클래스로 구성합니다. 텍스트 없는 상태 점은 `w2:group.badge_dot-only`에 `role="status"`와 접근성 이름을 지정합니다. 겹침 배지는 `w2:group.badge_wrap` 안에서 버튼·Avatar 등의 기준 요소 다음에 배치합니다.

숫자나 상태가 화면 데이터에 따라 바뀌면 `label`과 접근성 이름을 함께 갱신합니다. 겹침 대상이 클릭 가능한 경우 Badge 자체에 별도 클릭 이벤트를 중복 연결하지 않습니다.
