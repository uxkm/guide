# Tree

파일·조직·메뉴처럼 계층이 있는 데이터를 탐색하고 선택합니다. `TreeNode`는 확장·선택·비활성·메타 상태를 제공합니다.

Vue와 React 구현은 각각 `@uxkm/vue/tree`, `@uxkm/react/tree`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

WebSquare는 `tree`·`treeitem`·`group` 역할을 갖는 중첩 `w2:group`과 확장 Trigger, 선택 Checkbox를 계층 데이터에 연결합니다.

## 컴포넌트 구현 코드

아래 코드는 Tree와 TreeNode의 실제 HTML·Gulp·Vue·React 원본 구현입니다. 계층 구조, 확장·선택·비활성 상태, 토글·체크박스·메타 영역의 구성을 확인할 수 있습니다.

<FrameworkTabs examples={treeComponentExamples} showFullCode />

## WebSquare 사용

루트에는 `role="tree"`, 노드에는 `role="treeitem"`, 자식 컨테이너에는 `role="group"`을 지정합니다. 노드 데이터의 expanded·selected·disabled 값을 `aria-expanded`·`aria-selected`와 상태 클래스에 함께 연결하고, 토글 Trigger의 레이블도 펼침 상태에 맞춰 갱신합니다.
