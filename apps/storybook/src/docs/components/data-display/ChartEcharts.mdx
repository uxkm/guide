# ChartEcharts

[Apache ECharts](https://echarts.apache.org/)를 사용하는 차트 컴포넌트입니다. 라이브러리 없는 `Chart`, Chart.js 기반 `ChartJs`와 같은 데이터 형태(`data`, `type`, `title` 등)를 지원합니다.

Vue는 `@uxkm/vue/chart-echarts`, React는 `@uxkm/react/chart-echarts`로 가져옵니다. Gulp는 `chartEcharts` Nunjucks 매크로와 `main.js`의 `initChartEcharts()`를 사용합니다.
HTML은 `data-chart-echarts-options`에 JSON을 넣고 `initChartEcharts()`로 초기화합니다.
공통 스타일 `styles/uxkm.css`를 함께 로드하세요.

`chartOptions`로 ECharts `option`을 깊게 병합할 수 있습니다. 유형은 `bar` · `line` · `area` · `donut` · `pie`입니다.

## 색상 커스텀

`Chart` · `ChartJs`와 동일한 CSS 변수(`--chart-color`, `--chart-series-*`)를 사용합니다. 렌더 시점에 CSS 변수를 계산된 색상으로 해석합니다.

## ECharts 옵션 확장

```jsx
<ChartEcharts
  type="bar"
  data={data}
  chartOptions={{
    series: [{ barWidth: "40%" }],
  }}
/>
```
