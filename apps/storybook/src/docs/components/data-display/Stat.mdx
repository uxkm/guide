# Stat

핵심 수치와 라벨, 설명, 추세를 강조해 표시합니다. 크기·접두·접미·아이콘·레이아웃·카드 스킨과 반응형 그룹을 제공합니다.

Vue와 React 구현은 각각 `@uxkm/vue/stat`, `@uxkm/react/stat`으로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

WebSquare는 `w2:group` 안에 label·value·prefix·suffix·description `w2:textbox`를 배치하고 각 값을 화면 데이터에 연결합니다.

## 컴포넌트 구현 코드

아래 코드는 Stat의 실제 HTML·Gulp·Vue·React 원본 구현입니다. 값 구성, 크기·배치·카드 스킨, 추세 색상과 그룹 클래스가 적용되는 방식을 확인할 수 있습니다.

<FrameworkTabs examples={statComponentExamples} showFullCode />

## WebSquare 사용

라벨·값·접두·접미·추세 설명은 독립된 `w2:textbox`로 구성해 데이터 바인딩과 갱신 범위를 분리합니다. 여러 지표는 `w2:group.stat_group`으로 묶고, 증감 의미는 텍스트와 `color_*`를 함께 갱신해 색상에만 의존하지 않습니다.
