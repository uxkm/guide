# Calendar

날짜를 월·주 단위 그리드, 세로 일정 목록, iOS 스타일 휠로 표시하는 캘린더 컴포넌트입니다.

Vue와 React 구현은 각각 `@uxkm/vue/calendar`, `@uxkm/react/calendar`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.
