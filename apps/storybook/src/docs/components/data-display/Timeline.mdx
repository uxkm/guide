# Timeline

시간순 이벤트와 프로세스 흐름을 표시합니다. `TimelineItem`은 시간·제목·설명·상태·메타 정보를 일관되게 배치합니다.

Vue와 React 구현은 각각 `@uxkm/vue/timeline`, `@uxkm/react/timeline`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

WebSquare는 `w2:group`의 `ol`·`li`·`time` tagname으로 시간순 의미를 유지하고 이벤트 목록을 DataList와 `w2:generator`로 반복합니다.

## 컴포넌트 구현 코드

아래 코드는 Timeline과 TimelineItem의 실제 HTML·Gulp·Vue·React 원본 구현입니다. 방향·크기·도트·카드·상태 클래스와 시간·제목·설명 영역의 구성을 확인할 수 있습니다.

<FrameworkTabs examples={timelineComponentExamples} showFullCode />

## WebSquare 사용

Timeline은 `ol`, 각 항목은 `li`, 시간 값은 `time` tagname을 사용합니다. 반복 이벤트는 DataList와 generator에 연결하며, 상태 색상은 dot 클래스와 텍스트 설명을 함께 제공해 의미를 보존합니다. 단순 표시 컴포넌트이므로 별도 이벤트는 필요하지 않습니다.
