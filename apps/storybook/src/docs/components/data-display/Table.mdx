# Table

행과 열로 구조화된 데이터를 표시합니다. 테두리·줄무늬·밀도·호버 상태와 열 크기, 가로·세로 스크롤, 상단·좌측 고정을 공통 API로 제공합니다.

Vue와 React 구현은 각각 `@uxkm/vue/table`, `@uxkm/react/table`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

## 기본

`columns`로 열 너비·최소 너비·패딩·줄바꿈을 지정하고 내부에는 시맨틱 `thead`·`tbody`를 작성합니다.
