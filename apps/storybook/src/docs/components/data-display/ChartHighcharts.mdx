# ChartHighcharts

[Highcharts](https://www.highcharts.com/)를 사용하는 차트 컴포넌트입니다. `Chart` · `ChartJs` · `ChartEcharts`와 같은 데이터 형태를 지원합니다.

- React: `@uxkm/react/chart-highcharts`
- Vue: `@uxkm/vue/chart-highcharts`
- HTML: `data-chart-highcharts-options` + `initChartHighcharts()`
- Gulp: `chartHighcharts` 매크로

유형: `bar` · `line` · `area` · `donut` · `pie`. `chartOptions`로 Highcharts 옵션을 병합합니다.

> Highcharts는 상용 라이선스가 필요할 수 있습니다. 프로젝트 라이선스 정책을 확인하세요.
