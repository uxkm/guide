# ChartHighcharts

**라이선스: 유료 (상용 시)** — [Highcharts](https://www.highcharts.com/)는 비상업·개인·교육 등 일부 조건에서는 무료일 수 있으나, **상용 제품·서비스에는 Highcharts 상용 라이선스 구매가 필요**합니다. 도입 전 [라이선스·가격](https://shop.highcharts.com/)을 확인하세요.

Highcharts를 사용하는 차트 컴포넌트입니다. `Chart` · `ChartJs` · `ChartEcharts`와 같은 데이터 형태를 지원합니다.

- React: `@uxkm/react/chart-highcharts`
- Vue: `@uxkm/vue/chart-highcharts`
- HTML: `data-chart-highcharts-options` + `initChartHighcharts()`
- Gulp: `chartHighcharts` 매크로

유형: `bar` · `line` · `area` · `donut` · `pie`. `chartOptions`로 Highcharts 옵션을 병합합니다.

무료 대안이 필요하면 `Chart`(자체 SVG), `ChartJs`, `ChartEcharts`, `ChartD3`를 사용하세요. 전체 비교와 선택 가이드는 [Chart](?path=/docs/데이터-표시-chart--docs#라이선스--무료--유료) 문서를 참고하세요.
WebSquare 탭은 차트 계열에서 제공하지 않습니다. HTML·Gulp·Vue·React(및 Next/Nuxt 재사용)로 사용하세요.

## 색상 커스텀

`Chart` · `ChartJs` · `ChartEcharts`와 동일한 CSS 변수(`--chart-color`, `--chart-series-*`)를 사용합니다. 렌더 시점에 CSS 변수를 계산된 색상으로 해석합니다.

```css
:root {
  --chart-color: #2563eb;
  --chart-series-1: #2563eb;
  --chart-series-2: #0d9488;
  --chart-series-3: #9333ea;
  --chart-series-4: #c2410c;
}
```

## Highcharts 옵션 확장

`chartOptions`로 Highcharts 차트 옵션을 깊게 병합할 수 있습니다.

```jsx
<ChartHighcharts
  type="bar"
  data={data}
  chartOptions={{
    legend: { enabled: true, align: "right" },
    credits: { enabled: false },
  }}
/>
```

## 접근성

차트 영역에 제목을 `aria-label`로 제공합니다. `데이터 표 보기`로 원본 수치를 표로 확인할 수 있으며, 해당 컨트롤에도 제목을 포함한 `aria-label`을 둡니다. 상용 도입 시 Highcharts 접근성 모듈·라이선스 조건을 함께 확인하세요.
