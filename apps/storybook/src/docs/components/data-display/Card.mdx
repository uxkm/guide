# Card

콘텐츠를 그룹화하여 표시하는 카드 컴포넌트입니다.

Vue와 React 구현은 각각 `@uxkm/vue/card`, `@uxkm/react/card`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

WebSquare는 카드와 내부 영역을 `w2:group`, 텍스트를 `w2:textbox`, 카드 액션을 `xf:trigger` 또는 `w2:anchor`로 구성합니다. 각 WebSquare 탭의 코드는 화면 XML 루트에서 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 `Card`, `CardHeader`, `CardBody`, `CardFooter`, `CardDeck` 자체의 실제 원본 구현입니다. React와 Vue는 prop·slot을 루트 의미, 내부 구조, 공통 클래스와 접근성 상태로 변환합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 그대로 재사용합니다.

- `variant`·`size`·`horizontal`·`compact`·`hoverable`·`accent`는 대응 `card_*` 클래스로 변환됩니다.
- `href`가 있으면 링크, 클릭 핸들러가 있으면 버튼, 그 외에는 기본 `article` 루트를 사용합니다.
- 비활성 인터랙티브 Card는 기본 동작을 차단하고 `aria-disabled`와 `tabIndex=-1`을 적용합니다.
- `media`, 내장 header, `CardHeader`·`CardBody`·`CardFooter`를 조합해 필요한 구조만 렌더링합니다.
- `CardDeck`은 자동 반응형 그리드를 제공하며 `columns`로 2열 또는 3열 클래스를 선택합니다.

## WebSquare 사용

Card는 별도 WFrame을 불러오는 컴포넌트가 아니라 화면 XML의 `w2:group`에 `card`와 변형 클래스를 적용하는 구조입니다. Header·Body·Footer·Media도 중첩 `w2:group`으로 구성하고 텍스트는 `w2:textbox`의 `tagname`으로 제목과 본문의 의미를 유지합니다.

URL 이동 Card는 `w2:anchor`, 화면 동작 Card와 내부 버튼은 `xf:trigger` 또는 `ev:onclick`을 사용합니다. 비활성 Card는 이벤트를 연결하지 않고 `is-disabled`와 접근성 상태를 함께 적용합니다. 반복 카드 목록은 DataList와 `w2:generator`로 만들 수 있습니다.
