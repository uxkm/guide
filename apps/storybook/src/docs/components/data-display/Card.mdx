# Card

콘텐츠를 그룹화하여 표시하는 카드 컴포넌트입니다.

Vue와 React 구현은 각각 `@uxkm/vue/card`, `@uxkm/react/card`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

## 기본

`card_header` · `card_body` · `card_footer` 구조를 가집니다.

<FrameworkTabs examples={cardFrameworkExamples.basic} />
