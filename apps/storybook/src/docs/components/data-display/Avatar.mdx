# Avatar

사용자·조직을 이미지, 이니셜 또는 아이콘으로 표현합니다. 크기·형태·색상·상태 점과 겹침 그룹을 공통 API로 제공합니다.

Vue와 React 구현은 각각 `@uxkm/vue/avatar`, `@uxkm/react/avatar`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

## 기본

이미지가 있으면 `avatar_image`로 표시하고, 로드에 실패하거나 이미지가 없으면 아이콘·자식·이니셜 순서로 대체합니다.
