# Avatar

사용자·조직을 이미지, 이니셜 또는 아이콘으로 표현합니다. 크기·형태·색상·상태 점과 겹침 그룹을 공통 API로 제공합니다.

Vue와 React 구현은 각각 `@uxkm/vue/avatar`, `@uxkm/react/avatar`로 제공하며 Nuxt와 Next.js에서도 같은 구현을 재사용합니다.

WebSquare는 `w2:group`과 `w2:textbox`에 공통 Avatar 클래스를 적용하고, 프로필 이미지는 `w2:image`로 배치합니다. 각 WebSquare 탭의 코드는 화면 XML 루트에서 `w2` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 `Avatar`와 `AvatarGroup` 컴포넌트 자체의 구현입니다. React와 Vue는 전달받은 prop을 공통 CSS 클래스와 접근성 속성으로 변환하고, HTML과 Gulp는 같은 클래스와 내부 구조를 마크업에 직접 적용합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 그대로 재사용합니다.

- `src` 이미지가 있으면 `avatar_image`를 렌더링하고, 로드에 실패하면 아이콘·자식 콘텐츠·이니셜 순서로 대체합니다.
- `size`·`square`·`color`는 `avatar_*`·`color_*` 클래스로 변환됩니다. `md` 크기는 기본값이라 별도 클래스를 붙이지 않습니다.
- `badgeColor`는 `avatar_badge color_*` 상태 점을 만들며, `badgeLabel`로 상태 의미를 제공합니다.
- 장식용 아바타는 `ariaHidden` 또는 `aria-hidden`으로 숨기고, 의미 있는 이미지에는 내용을 식별하는 `alt`를 지정합니다.
- `AvatarGroup`은 겹침 레이아웃과 `role="group"`을 적용하고 `ariaLabel`로 그룹 목적이나 인원을 설명합니다.

## WebSquare 사용

WebSquare에는 별도 Avatar 컴포넌트 파일을 두지 않고 화면 XML의 `w2:group`·`w2:textbox`에 `avatar`, `avatar_*`, `color_*` 클래스를 조합합니다. 이미지 아바타는 `w2:group.avatar` 안에 `w2:image.avatar_image`를 배치합니다. 상태 점은 아바타 내부의 `w2:group.avatar_badge`로 만들고 상태를 설명하는 접근성 이름을 지정합니다.

이미지와 아이콘 경로는 프로젝트의 정적 리소스 위치에 맞게 변경합니다. 반복되는 사용자 목록은 DataList와 `w2:generator`로 만들 수 있으며, 화면 데이터가 바뀔 때 이니셜·색상·이미지 경로를 함께 갱신합니다.
