# Typography

제목, 본문, 강조, 말줄임 등 텍스트 표현에 일관된 위계와 시맨틱 태그를 적용하는 컴포넌트입니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/typography`, `@uxkm/react/typography`의 `TypoTitle`·`TypoText`로 제공합니다. Nuxt와 Next.js는 같은 구현을 재사용합니다.

WebSquare는 자식 요소가 없는 제목과 텍스트를 `w2:textbox`로 표현하고, `tagname`에 `h1`·`p`·`span`·`strong` 등의 시맨틱 태그를 지정합니다. Textbox는 자식 컴포넌트를 가질 수 없으므로 인라인 혼합 콘텐츠와 중첩 목록은 `w2:group` 또는 XML 호환 XHTML 구조를 유지합니다. 각 예시의 WebSquare 탭은 화면 루트의 공통 네임스페이스를 상속합니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 `TypoTitle`과 `TypoText` 컴포넌트 자체의 구현입니다. React와 Vue는 전달받은 prop을 시맨틱 태그와 공통 CSS 클래스로 변환하고, HTML은 같은 클래스를 마크업에 직접 적용하며, Gulp는 `typoTitle` · `typoText` Nunjucks macro로 동일한 계약을 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 그대로 재사용합니다.

- `TypoTitle`의 `level`은 1~5만 허용하며 `h1`~`h5`와 `typo_title-*`를 같은 단계로 맞춥니다.
- `TypoText`의 `variant`는 기본 태그와 `typo_*` 클래스를 선택합니다. `tag`로 루트 요소를 덮어쓸 수 있습니다.
- `color`·`size`·`ellipsis`는 공통 색상·크기·말줄임 클래스로 변환됩니다.
- `link`·`label`·`blockquote` variant는 각각 `href`·`htmlFor`·`cite`를 루트에 전달합니다.
- React의 `children` 또는 Vue의 기본 slot과 `label`은 텍스트 콘텐츠로 사용됩니다. Gulp는 `label` 또는 `{% call %}` 본문을 사용합니다.

## WebSquare 사용

고정 문구는 `label`, 동적 문구는 DataCollection `ref` 또는 `setValue()`로 연결합니다. 제목 단계는 화면의 시각적 크기가 아니라 문서 구조에 맞춰 `tagname="h1"`부터 `h5`까지 선택하고 같은 단계의 `typo_title-*` 클래스를 적용합니다.

## 제목

`typo_title-1`부터 `typo_title-5`까지 5단계 제목 스케일을 제공합니다. 문서 구조에 맞는 동일 레벨의 시맨틱 heading 태그를 사용합니다.
