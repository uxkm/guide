# Typography

제목, 본문, 강조, 말줄임 등 텍스트 표현에 일관된 위계와 시맨틱 태그를 적용하는 컴포넌트입니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/typography`, `@uxkm/react/typography`의 `TypoTitle`·`TypoText`로 제공합니다. Nuxt와 Next.js는 같은 구현을 재사용합니다.

## 제목

`typo_title-1`부터 `typo_title-5`까지 5단계 제목 스케일을 제공합니다. 문서 구조에 맞는 동일 레벨의 시맨틱 heading 태그를 사용합니다.

<Canvas of={TypographyStories.Titles} sourceState="none" />
<FrameworkTabs examples={typographyFrameworkExamples.titles} />

## 본문

기본 본문은 별도 클래스 없이 `p`를 사용합니다. 단락 사이의 간격이 필요하면 `typo_paragraph`를 적용합니다.

<Canvas of={TypographyStories.Body} sourceState="none" />
<FrameworkTabs examples={typographyFrameworkExamples.body} />

## 색상 타입

`color_muted`, `color_success` 등 공통 색상 클래스를 사용합니다. 다른 컴포넌트에서도 같은 색상 계약을 공유합니다.

<Canvas of={TypographyStories.Colors} sourceState="none" />
<FrameworkTabs examples={typographyFrameworkExamples.colors} />

## 크기

base는 별도 클래스 없이 적용되며 xs, sm, lg, xl은 각각 공통 `size_*` 클래스를 사용합니다.

<Canvas of={TypographyStories.Sizes} sourceState="none" />
<FrameworkTabs examples={typographyFrameworkExamples.sizes} />

## 텍스트 스타일

강조, 기울임, 밑줄, 취소선, 형광펜, 인라인 코드 등 인라인 스타일을 의미에 맞는 태그와 조합합니다.

<Canvas of={TypographyStories.InlineStyles} sourceState="none" />
<FrameworkTabs examples={typographyFrameworkExamples.styles} />

## 아래첨자 · 위첨자 · 소문자

`sub` · `sup` · `small` 시맨틱 태그에 `typo_sub` · `typo_sup` · `typo_small`을 적용합니다.

<Canvas of={TypographyStories.SubSupSmall} sourceState="none" />
<FrameworkTabs examples={typographyFrameworkExamples.subSup} />

## 말줄임

`text_ellipsis`로 1줄, `text_ellipsis-2`·`text_ellipsis-3`으로 여러 줄 말줄임을 적용합니다. 부모에 너비 제한이 필요합니다.

<Canvas of={TypographyStories.Ellipsis} sourceState="none" />
<FrameworkTabs examples={typographyFrameworkExamples.ellipsis} />

## 인용

`blockquote` 태그와 `typo_blockquote`를 사용하고, 출처가 있다면 `cite`에 URL을 지정합니다.
