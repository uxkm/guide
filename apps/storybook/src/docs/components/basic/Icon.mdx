# Icon

SVG 아이콘의 이름·크기·색상·정렬·상태를 일관된 규칙으로 제공하는 기본 요소입니다. stroke 아이콘은 `currentColor`로 부모 색상을 상속합니다.

Vue와 React의 공통 구현은 각각 `@uxkm/vue/icon`, `@uxkm/react/icon`으로 제공합니다. Nuxt와 Next.js 예시는 같은 구현을 재사용하므로 코드 탭의 경로도 실제 공통 소스를 가리킵니다.

## 기본

`name`에 제공 아이콘 이름을 지정합니다. 별도 색상을 지정하지 않으면 주변 텍스트의 색상을 상속합니다.

## 커스텀 SVG

`path`, `circle` 등 SVG 도형을 자식으로 전달할 수 있습니다. 커스텀 도형은 `name`보다 우선합니다.

## 크기

small, medium, large, extra large 네 가지 크기를 제공합니다. medium은 기본 `icon`, 나머지는 `icon_sm` · `icon_lg` · `icon_xl` 클래스를 사용합니다.

## 색상

공통 `color_*` 유틸리티로 default, primary, success, warning, danger, info, muted 색상을 적용합니다.

## 텍스트 인라인

`inline` 또는 `icon_inline`으로 텍스트 기준선에 맞춥니다. 의미가 있는 아이콘에는 `aria-label`을 지정합니다.

## 원형 · 사각형 배경

`circle` · `square` 또는 `icon_circle` · `icon_square`로 배경형 아이콘을 만듭니다. circle은 small, medium, large 크기를 지원합니다.
