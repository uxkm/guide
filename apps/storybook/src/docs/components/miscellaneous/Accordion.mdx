# Accordion

여러 섹션을 접었다 펼 수 있는 컴포넌트입니다. FAQ·설정·필터 패널 등에 사용하며 단일 또는 다중 열기와 키보드 탐색을 지원합니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

트리거와 패널은 `aria-expanded`, `aria-controls`, `aria-labelledby`로 연결됩니다. `ArrowUp`, `ArrowDown`, `Home`, `End` 키로 활성 트리거 사이를 이동하며 비활성 항목은 건너뜁니다.

WebSquare는 루트를 `w2:group.accordion`, 트리거를 `xf:trigger`, 패널을 `w2:group.accordion_panel`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Accordion과 AccordionItem의 실제 원본 구현입니다. React와 Vue는 다중 열기, flush·bordered 변형, 크기, 슬라이드 효과와 키보드 탐색을 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `multiple`은 여러 패널을 동시에 열 수 있게 합니다.
- `variant`는 bordered·flush·card 외형을 전환합니다.
- 트리거와 패널은 `aria-expanded`·`aria-controls`로 연결합니다.

## WebSquare 사용

`w2:group.accordion` 안에 항목을 배치하고 트리거는 `xf:trigger`의 `ev:onclick`에서 `aria-expanded`와 패널 표시를 동기화합니다. 다중 열기는 `data-accordion-multiple`로 표현합니다.
