# Collapse

콘텐츠 영역을 접었다 펼 수 있는 컴포넌트입니다. 외부 버튼으로 단일 영역을 제어하거나 패널 그룹으로 여러 섹션을 구성할 수 있습니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

트리거와 패널은 `aria-expanded`, `aria-controls`, `aria-labelledby`로 연결됩니다. 패널 그룹에서는 `ArrowUp`, `ArrowDown`, `Home`, `End` 키로 활성 트리거 사이를 이동합니다.

WebSquare는 그룹을 `w2:group.collapse_group`, 외부 트리거를 `xf:trigger`, 본문을 `w2:group.collapse_body`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Collapse와 CollapsePanel·CollapseExternal의 실제 원본 구현입니다. React와 Vue는 외부 트리거, 패널 그룹, 단일 열기, 스킨, 크기와 슬라이드 효과를 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `accordion`은 한 번에 하나의 패널만 엽니다.
- `CollapseExternal`은 외부 버튼으로 단일 영역을 제어합니다.
- 트리거와 패널은 `aria-expanded`·`aria-controls`로 연결합니다.

## WebSquare 사용

`w2:group.collapse_group`에 패널을 배치하거나 외부 `xf:trigger`로 본문을 제어합니다. 단일 열기는 `data-collapse-accordion`으로 표현하고, 토글은 `ev:onclick`에서 처리합니다.
