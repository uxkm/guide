# Carousel

여러 콘텐츠를 가로로 탐색하는 Swiper 기반 캐러셀입니다. 키보드·터치 탐색과 다양한 전환 효과, 페이지네이션, 자동 재생을 지원합니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

루트 슬라이더는 `role="region"`, `aria-roledescription="carousel"`, `aria-label`을 제공합니다. 이전·다음 버튼, 페이지네이션, 자동 재생 토글은 키보드로 조작할 수 있습니다.

WebSquare는 루트를 `w2:group.carousel`, 슬라이드를 `w2:group.swiper-slide`, 이전·다음을 `xf:trigger`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Carousel과 CarouselSlide의 실제 원본 구현입니다. React와 Vue는 페이드·커버플로우, 자동 재생, 다중 슬라이드, 페이지네이션과 썸네일 연결을 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `effect`로 fade·coverflow 전환을 선택합니다.
- `pagination`은 bullets·fraction·progressbar·custom을 지원합니다.
- 루트는 `role="region"`과 `aria-roledescription="carousel"`을 사용합니다.

## WebSquare 사용

`w2:group.carousel`에 `role="region"`과 `aria-label`을 적용하고 슬라이드를 `swiper-wrapper` 안에 배치합니다. 이전·다음은 `xf:trigger`의 `ev:onclick`에서 화면 스크립트로 이동합니다.
