# BackTop

스크롤 후 페이지 또는 컨테이너 상단으로 부드럽게 이동하는 플로팅 버튼입니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

아이콘만 사용하는 버튼에는 동작을 설명하는 `aria-label`이 필요합니다. 키보드로 버튼에 접근하고 실행할 수 있어야 합니다.

WebSquare는 루트를 `w2:group.back_top`, 버튼을 `xf:trigger.back_top_btn`으로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 BackTop의 실제 원본 구현입니다. React와 Vue는 표시 임계값, 크기, 색상, 커스텀 콘텐츠와 스크롤 대상을 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `visibilityHeight`로 버튼 표시 임계값을 설정합니다.
- `target`으로 페이지 또는 컨테이너 스크롤을 지정합니다.
- 아이콘 전용 버튼은 `aria-label`로 동작을 설명합니다.

<FrameworkTabs examples={backTopComponentExamples} showFullCode />

## WebSquare 사용

`w2:group.back_top`에 `data-target`과 `data-visibility-height`를 적용하고 버튼은 `xf:trigger`의 `ev:onclick`에서 상단으로 스크롤합니다. 아이콘만 사용할 때는 `aria-label`을 반드시 제공합니다.
