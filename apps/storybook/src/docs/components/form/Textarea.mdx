# Textarea

여러 줄의 긴 텍스트를 입력하는 필드 컴포넌트입니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

모든 textarea에는 접근 가능한 이름을 제공합니다. 일반 필드는 `label[for]`와 `id`를 연결하고, 보이는 label이 없는 단독 입력은 `input_group-label_hidden` 텍스트와 textarea를 하나의 `display_contents` label로 감싸 암묵적으로 연결합니다. 오류와 도움말은 `aria-describedby`로 연결하고, 글자 수 카운터는 시각 텍스트와 스크린 리더용 상태 문구를 함께 제공합니다.

WebSquare는 여러 줄 입력을 `xf:textarea`, 레이블·상태·카운터 영역을 `w2:group`과 `w2:textbox`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Textarea 자체의 실제 원본 구현입니다. React와 Vue는 제어·비제어 값, 크기 조절 방향, 오류 상태, 최대 글자 수와 접근 가능한 카운터를 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- `size`와 `resize` 값을 검증해 대응 `textarea_*` 클래스로 변환합니다.
- 글자 수 표시는 고유 id를 만들고 기존 `aria-describedby`와 카운터 id를 함께 유지합니다.
- 최대 길이에 도달하면 `is-limit` 상태를 적용하고 시각 텍스트와 스크린 리더 문구를 분리합니다.
- 카운터를 사용하지 않을 때는 네이티브 textarea를 직접 반환해 불필요한 wrapper를 만들지 않습니다.

## WebSquare 사용

`xf:textarea`의 `ref`를 데이터 경로에 연결하고 `rows`, `maxlength`, `mandatory`, `disabled`를 입력 요구사항에 맞게 설정합니다. 크기 조절과 너비는 `textarea_resize_*`, `textarea_fit` 클래스로 표현합니다.

글자 수가 필요하면 `textarea_wrap` 안에 `w2:textbox.textarea_count`를 배치하고 입력 이벤트에서 현재 길이를 갱신합니다. 카운터에는 `role="status"`와 `aria-live="polite"`를 적용하고 오류·도움말 id는 입력의 설명 관계에 포함합니다.
