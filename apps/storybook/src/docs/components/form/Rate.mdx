# Rate

별점과 만족도를 선택하거나 읽기 전용으로 표시하는 Rate 컴포넌트입니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

`fieldset`과 `input type="radio"`를 기반으로 반점 선택과 초기화를 지원합니다. 그룹 목적은 `legend`로 전달합니다.

WebSquare는 별점 입력을 `xf:input`(type=`radio`), 초기화를 `xf:trigger`, 별·범례 영역을 `w2:group`과 `w2:textbox`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Rate 자체의 실제 원본 구현입니다. React와 Vue는 제어·비제어 별점, 반점, 초기화, 읽기 전용과 접근성 레이블을 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- 지원하지 않는 크기는 `md`로 정규화하고 `rate_sm`·`rate_lg` 클래스로 변환합니다.
- `allowHalf`는 0.5점 단위 선택을, `clearable`은 선택 초기화를 제공합니다.
- 읽기 전용은 상호작용을 막고 현재 별점만 표시합니다.
- 각 별은 radio 입력과 그래픽·숨김 레이블로 접근 가능한 이름을 제공합니다.

## WebSquare 사용

같은 `name`과 `ref`를 공유하는 `xf:input type="radio"`로 별점 그룹을 구성합니다. 선택값은 DataMap 경로에 바인딩하고 `value`는 정수(또는 반점 규칙에 맞는 값)로 저장합니다.

초기화는 `xf:trigger`의 `ev:onclick`에서 값을 비웁니다. 선택 변경 후 연관 필드를 갱신할 때는 `ev:onchange`를 화면 스크립트에 연결합니다.
