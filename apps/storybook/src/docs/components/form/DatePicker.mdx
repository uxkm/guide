# DatePicker

날짜 입력 트리거와 달력 패널을 결합한 폼 컴포넌트입니다. 값은 모든 프레임워크에서 `YYYY-MM-DD`로 주고받고 화면에는 locale 형식으로 표시합니다.

## 기본

입력 또는 달력 버튼으로 패널을 열고 날짜를 선택합니다. Escape와 바깥 영역 클릭으로 패널을 닫을 수 있습니다.
