# Input

텍스트·숫자·검색 등 한 줄 입력을 위한 필드 컴포넌트입니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

모든 input에는 연결된 label을 제공합니다. 일반 필드는 `label[for]`와 `id`를 연결하고, 카드번호·OTP처럼 여러 input이 하나의 그룹을 이루는 경우에는 그룹명을 `aria-labelledby`로 연결한 뒤 각 input을 `display_contents` label로 감싸 암묵적으로 연결합니다. 화면에 레이블을 표시하지 않는 검색·애드온 입력은 `input_group-label_hidden` 레이블을 사용합니다. 클리어 버튼이 있는 입력은 label 안에 다른 버튼을 중첩하지 않도록 숨김 label과 input을 명시적으로 연결합니다.
