# Radio

같은 그룹에서 하나의 항목만 선택하는 라디오 컴포넌트입니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

관련 항목은 같은 `name`을 사용하고 `fieldset`과 `legend`(또는 `aria-labelledby`)로 그룹의 목적을 제공합니다. 보이는 레이블이 없는 단독 사용은 `aria-label`로 접근 가능한 이름을 제공합니다.

WebSquare는 라디오 입력을 `xf:input`(type=`radio`) 또는 그룹 선택에 `xf:select1`, 레이블·그룹·카드 영역을 `w2:group`과 `w2:textbox`로 구성합니다. 각 WebSquare 탭은 화면 XML 루트에 `w2`, `xf`, `ev` 네임스페이스가 선언되어 있다는 전제의 fragment입니다.

## 컴포넌트 구현 코드

아래 코드는 사용 예제가 아니라 Radio 자체의 실제 원본 구현입니다. React와 Vue는 제어·비제어 선택 상태, `name`·`value`, 레이블 배치, 버튼형 변형과 접근성 속성을 공통 API로 제공합니다. Next.js는 React 구현을, Nuxt는 Vue 구현을 재사용합니다.

- 같은 `name`을 공유하는 항목만 서로 배타적으로 선택됩니다.
- 레이블이 없으면 `radio_control` 단독 마크업과 `aria-label`을 사용합니다.
- `labelEnd`·`button`은 루트 클래스로 레이아웃·버튼형 변형을 적용합니다.
- `ripple`은 전체 Radio 영역을 기준으로 클릭 파장 효과를 표시합니다.

## WebSquare 사용

디자인 시스템 마크업을 유지할 때는 `xf:input`의 `type="radio"`와 동일한 `name`·`ref`로 그룹을 구성합니다. 선택지 목록을 DataList로 관리할 때는 `xf:select1`과 `w2:itemset`을 사용할 수 있습니다.

크기·색상·너비는 공통 `radio_*`, `color_*` 클래스로 표현하고, 상태 변경 후 연관 필드를 갱신할 때는 `ev:onchange`를 화면 스크립트에 연결합니다.
