# Select

정해진 선택지 중 하나 또는 여러 항목을 고르는 네이티브 select 컴포넌트입니다. React와 Vue 공통 패키지를 Next.js와 Nuxt에서도 재사용합니다.

일반 필드는 `label[for]`와 `id`를 연결합니다. 보이는 label이 없는 단독 선택은 `input_group-label_hidden` 텍스트와 select를 하나의 `display_contents` label로 감싸 암묵적으로 연결합니다. placeholder는 선택할 수 없는 빈 option으로 제공하며 필수 선택과 함께 사용할 수 있습니다.

다크 모드에서는 Select와 option 목록에 surface 배경과 고대비 텍스트 토큰을 사용합니다. 오류·성공 테두리는 어두운 surface에서 3:1 이상의 UI 대비를 확보하는 semantic text 색상을 적용합니다.
