# Naming Convention

이름은 프레임워크가 달라도 같은 개념을 빠르게 찾고 비교할 수 있도록 일관되게 작성합니다.

## 파일과 컴포넌트

- 컴포넌트와 디렉터리는 `PascalCase`를 사용합니다: `DatePicker`, `BackTop`.
- React 파일은 `.jsx`, Vue 파일은 `.vue`, Nunjucks 파일은 `kebab-case.njk`를 사용합니다.
- 공개 진입점은 각 컴포넌트 디렉터리의 `index.js`로 제공합니다.
- 테스트 파일은 구현 파일과 같은 디렉터리에 둡니다.

## API

- prop은 역할을 설명하는 `camelCase` 이름을 사용합니다: `ariaLabel`, `showInfo`.
- boolean은 긍정형 상태를 기본으로 작성합니다: `disabled`, `loading`, `block`.
- 이벤트는 React의 `onChange`, Vue의 `change`처럼 프레임워크 관례를 따르되 의미는 동일하게 유지합니다.
- 축약어보다 검색 가능한 전체 단어를 우선합니다.

## CSS

```text
.component
.component_element
.component_variant
.is-state
.color-semantic
.size-scale
```

시각적 결과가 아닌 의미를 이름에 담습니다. 기존 이름과 같은 의미의 별칭을 새로 추가하지 않습니다.
