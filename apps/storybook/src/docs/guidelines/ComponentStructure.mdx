# Component Structure

UXKM 컴포넌트는 여섯 프레임워크에서 같은 이름, 의미, 상태와 시각 결과를 제공하도록 구성합니다. HTML 구현을 시맨틱 마크업 기준으로 삼고 공통 스타일은 한 곳에서 관리합니다.

## 기본 파일 구조

```text
Category/Component/
├── Component.jsx 또는 Component.vue
├── Component.test.jsx 또는 Component.spec.js
└── index.js
```

## 추가 절차

1. 공통 API와 시맨틱 마크업을 결정합니다.
2. HTML, Gulp, Vue, React 구현을 동기화합니다.
3. Nuxt와 Next.js에서 재사용 또는 전용 통합을 확인합니다.
4. 공통 SCSS와 상태·접근성을 반영합니다.
5. Storybook Preview, 프레임워크 코드, API 문서를 추가합니다.
6. 구조 검사, 테스트, 정적 빌드를 실행합니다.

생성된 CSS나 Nuxt·Next 앱에 공통 컴포넌트를 복제하지 않습니다.
