## 공통으로 유지하는 것

- 사용자에게 보이는 이름과 동작
- CSS 클래스와 의미 토큰
- disabled, loading, error 등 상태 의미
- 키보드 조작과 ARIA 결과
- Storybook의 Preview와 API 설명

Nuxt와 Next.js는 52개 공통 컴포넌트를 복제하지 않고 각각 Vue와 React 원본을 재사용합니다. 프레임워크별 상세 문법은 Vue·React 가이드북에서 확인합니다.
