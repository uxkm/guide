# Accessibility Guide

이 문서는 컴포넌트 구현과 리뷰에서 사용하는 접근성 점검 절차입니다. 공통 원칙은 **파운데이션 / Accessibility**를 참고합니다.

## 구현 체크리스트

- 네이티브 요소로 해결할 수 있는지 먼저 확인합니다.
- 모든 입력에 프로그램 방식으로 연결된 레이블을 제공합니다.
- 아이콘 버튼과 이름 없는 영역에 접근 가능한 이름을 지정합니다.
- 상태 변화에 필요한 ARIA 속성을 실제 UI 상태와 동기화합니다.
- DOM 순서와 키보드 포커스 순서를 일치시킵니다.
- 오류 메시지를 해당 입력과 연결하고 복구 방법을 설명합니다.
- 라이트·다크 테마에서 텍스트, 경계, 포커스 대비를 확인합니다.

## 검수 순서

1. 마우스 없이 모든 기능을 실행합니다.
2. 200% 확대와 좁은 화면에서 콘텐츠 손실을 확인합니다.
3. 브라우저 접근성 트리에서 이름·역할·상태를 확인합니다.
4. 스크린 리더로 읽기 순서와 동적 알림을 확인합니다.
5. Storybook 접근성 검사 결과를 확인하고 수동 검수를 병행합니다.

자동 검사는 누락된 이름과 일부 대비 문제를 찾는 보조 수단입니다. 키보드 흐름, 메시지의 이해 가능성, 올바른 포커스 복귀는 반드시 직접 확인합니다.
