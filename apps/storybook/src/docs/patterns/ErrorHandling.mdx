# Error Handling

오류 메시지는 문제의 위치, 원인, 복구 방법을 함께 전달합니다. 기술적인 예외 문자열을 그대로 노출하지 않고 사용자가 취할 수 있는 행동을 중심으로 작성합니다.

## 처리 흐름

1. 사용자의 입력을 가능한 한 보존합니다.
2. 문제가 발생한 위치 가까이에 메시지를 표시합니다.
3. 오류 원인과 수정 방법을 구체적으로 설명합니다.
4. 재시도, 수정, 돌아가기 중 하나의 명확한 다음 행동을 제공합니다.
5. 복구되면 오래된 오류 상태와 `aria-invalid`를 제거합니다.

네트워크 오류는 무한 재시도하지 않으며, 중복 제출을 막고 요청 상태를 사용자에게 알립니다. 개발 로그의 상세 정보와 사용자용 메시지를 분리합니다.
