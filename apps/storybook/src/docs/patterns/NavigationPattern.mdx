# Navigation Pattern

내비게이션은 사용자가 현재 위치를 이해하고 원하는 영역으로 예측 가능하게 이동하도록 돕습니다. 정보 구조의 깊이와 이동 범위에 맞는 컴포넌트를 선택합니다.

## 원칙

- 현재 항목은 시각적 표시와 `aria-current` 등 의미 정보를 함께 제공합니다.
- 같은 목적지는 제품 전체에서 같은 이름과 위치를 유지합니다.
- 모바일에서 항목을 단순히 숨기지 말고 우선순위에 따라 재구성합니다.
- 탭, 페이지 이동, 펼침 메뉴의 동작을 서로 혼용하지 않습니다.
- 뒤로가기를 포함한 브라우저 탐색이 예측 가능해야 합니다.

메뉴 깊이는 가능한 한 얕게 유지하며, 사용자가 펼치지 않아도 주요 영역의 존재를 파악할 수 있게 합니다.
