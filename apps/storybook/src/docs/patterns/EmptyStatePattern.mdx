# Empty State Pattern

빈 상태는 단순히 데이터가 없다는 사실보다 왜 비어 있는지와 다음에 무엇을 할 수 있는지를 알려야 합니다.

## 구성

1. 선택적인 상태 아이콘 또는 이미지
2. 상황을 한 문장으로 설명하는 제목
3. 원인이나 해결 방법을 보충하는 설명
4. 가장 가능성 높은 다음 행동 하나

빈 상태를 오류나 로딩 상태 대신 사용하지 않습니다. 데이터 요청 중에는 Skeleton 또는 Spin을, 실패한 경우에는 Alert와 재시도 액션을 사용합니다. 실제 표현 API는 **피드백 / Empty** 문서를 참고합니다.
