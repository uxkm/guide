# Colors

색상은 실제 색상 이름이 아니라 배경, 텍스트, 강조, 성공, 위험처럼 역할을 나타내는 의미 토큰으로 사용합니다. 같은 컴포넌트가 라이트·다크 테마에서 동일한 의미를 유지하도록 합니다.

## 토큰 체계

```css
.notice {
  color: var(--color-text);
  background: var(--color-surface);
  border: 1px solid var(--color-border-subtle);
}
```

## 사용 원칙

- hex나 RGB 값을 컴포넌트에 직접 반복하지 않습니다.
- 채워진 면 위의 콘텐츠에는 `--color-on-*` 토큰을 사용합니다.
- 상태는 색상과 함께 아이콘, 제목 또는 설명 텍스트를 제공합니다.
- 새로운 토큰은 라이트와 다크 테마 값을 함께 정의합니다.
- 호버, 비활성, 포커스 상태의 대비까지 함께 검증합니다.

토큰의 실제 값은 `packages/styles/foundations/_themes.scss`에서 관리합니다.
