# Iconography

아이콘은 기능을 빠르게 인식하도록 돕는 보조 수단입니다. UXKM의 기본 아이콘은 `24 × 24` 좌표계와 `stroke-width="2"`를 사용하며 `currentColor`로 주변 텍스트 색상을 상속합니다.

텍스트와 함께 배치할 때는 기준선을 맞추고 아이콘과 레이블 사이에 일관된 간격을 둡니다. 버튼의 클릭 영역은 아이콘 자체 크기보다 충분히 크게 제공합니다.

## 접근성

- 옆 텍스트와 의미가 중복되는 장식 아이콘은 `aria-hidden="true"`로 숨깁니다.
- 아이콘만 있는 버튼에는 `aria-label`을 지정합니다.
- 정보 자체를 전달하는 비인터랙티브 아이콘에는 대체 설명을 제공합니다.
- 아이콘 모양이나 색상 하나만으로 성공·오류 상태를 구분하지 않습니다.

## 선택 원칙

한 기능에는 제품 전체에서 같은 아이콘을 사용합니다. 장식 목적으로 아이콘을 과도하게 사용하지 않으며, 새로운 아이콘은 기존 선 굵기·모서리·좌표계와 시각적 무게를 맞춥니다. 실제 이름과 사용 API는 **기본 요소 / Icon** 문서를 참고합니다.
