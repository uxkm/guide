# Breakpoints

UXKM은 콘텐츠가 실제로 재배치되어야 하는 지점을 기준으로 두 개의 공통 중단점을 사용합니다. 특정 기기 이름보다 사용 가능한 너비와 콘텐츠 우선순위에 집중합니다.

## 공통 값

  ]}
  codeColumns={[0]}
/>

중단점은 `packages/styles/shared/_variables.scss`의 SCSS 변수로 관리합니다. 런타임 테마 값이 아니므로 CSS 변수로 재정의하지 않습니다.

```scss
.content-grid {
  display: grid;
  grid-template-columns: 1fr;

  @media (min-width: $breakpoint-md) {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }

  @media (min-width: $breakpoint-lg) {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}
```

## 적용 원칙

- 모바일 기본 스타일을 먼저 작성합니다.
- 단순히 화면 크기가 바뀌었다는 이유로 중단점을 추가하지 않습니다.
- 고정 너비 대신 `minmax()`, `flex-wrap`, 상대 단위를 우선합니다.
- 200% 확대와 긴 한국어·영문 텍스트에서도 가로 스크롤이 생기지 않는지 확인합니다.
