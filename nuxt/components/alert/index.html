Alert

Alert

중요한 정보나 피드백을 사용자에게 전달하는 알림 컴포넌트입니다.

기본

공통 color_* 클래스로 info · success · warning · error 네 가지 의미를 표현합니다.

정보

변경 사항이 저장되었습니다.

성공

요청이 성공적으로 처리되었습니다.

주의

세션이 곧 만료됩니다. 저장해 주세요.

오류

네트워크 연결을 확인해 주세요.

설명만

제목 없이 alert_desc만으로 짧은 메시지를 표시합니다.

새 기능이 추가되었습니다. 설정에서 확인해 보세요.

프로필이 업데이트되었습니다.

아이콘 없음

alert_icon을 생략해 텍스트만 표시합니다. 간단한 안내에 적합합니다.

점검 안내

오늘 02:00~04:00 서비스 점검이 예정되어 있습니다.

이 페이지는 데모 목적으로만 사용됩니다.

크기

alert_sm · alert_lg로 스케일을 조절합니다.

Small

폼 필드 아래 등 좁은 영역에 사용합니다.

Medium

기본 크기입니다.

Large

페이지 상단 등 눈에 띄는 안내에 사용합니다.

닫기 가능

alert_close 버튼으로 사용자가 알림을 닫을 수 있습니다. aria-label로 닫기 동작을 설명합니다.

새 소식

대시보드가 새롭게 개편되었습니다.

브라우저가 오래되었습니다. 최신 버전으로 업데이트해 주세요.

액션

actions 슬롯에 확인·취소 등 후속 동작을 전달하면 alert_actions 영역에 배치됩니다.

저장 실패

변경 사항을 저장하지 못했습니다. 다시 시도해 주세요.

이용 약관 변경

2026년 3월 1일부터 새 약관이 적용됩니다.

배너

alert_banner로 페이지 상단 전체 너비 알림을 표시합니다. 좌우 테두리와 모서리 반경을 제거합니다.

시스템 점검으로 일부 기능이 제한될 수 있습니다.

문맥 속 사용

폼·카드 등 다른 컴포넌트와 함께 사용합니다. 설명 안에 링크를 포함할 수 있습니다.

클래스 · 속성

Vue 컴포넌트가 렌더하는 OOCSS 클래스입니다. HTML 마크업으로 직접 작성할 때 동일하게 조합합니다.

클래스설명
alert알림 루트
alert_sm · alert_lg크기
alert_icon · alert_body · alert_title · alert_desc · alert_actions구조 파트
alert_close닫기 버튼
color_info · color_success · color_warning · color_error의미 색상
data-ripple클릭 파장 활성. data-ripple="surface"는 절대 위치 보조 버튼용
data-ripple="false"해당 요소 ripple 비활성
data-no-ripple하위 전체 ripple 비활성
