Space

자식 요소 사이 간격을 일관되게 맞추는 flex 기반 레이아웃 유틸리티입니다. gap·방향·정렬·줄바꿈을 클래스로 조합합니다.

기본

space는 가로 inline-flex이며 기본 간격은 --space-gap (md)입니다.

API · Props

Prop타입기본값설명
verticalbooleanfalse세로 방향 배치 (space_vertical)
wrapbooleanfalse줄바꿈 허용 (space_wrap)
blockbooleanfalse부모 너비 100% flex (space_block)
gap'xs' | 'sm' | 'md' | 'lg' | 'xl'md자식 간 간격. md는 클래스 없이 --space-gap 사용
align'start' | 'center' | 'end' | 'baseline' | 'stretch'—교차축 정렬 (space_align-*)
justify'start' | 'center' | 'end' | 'between'—주축 정렬 (space_justify-*)

클래스 · 속성

Vue 컴포넌트가 렌더하는 OOCSS 클래스입니다. HTML 마크업으로 직접 작성할 때 동일하게 조합하며, id · style · aria-* 등 전달 속성은 루트 요소에 적용됩니다.

클래스설명
spaceinline-flex 루트, 기본 가로 배치
space_vertical세로 방향
space_wrap줄바꿈
space_blockdisplay flex + width 100%
space_gap-xs · space_gap-sm · space_gap-lg · space_gap-xl간격 변형 (md는 기본)
space_align-start · space_align-center · space_align-end · space_align-baseline · space_align-stretch교차축 정렬
space_justify-start · space_justify-center · space_justify-end · space_justify-between주축 정렬
