페이지 이동·액션 트리거용 하이퍼링크 컴포넌트입니다. 본문 안 인라인 링크는 Typography의 typo_link를 사용합니다.

기본

기본 색상은 primary입니다. hover 시 밑줄이 표시됩니다.

이미지 · 아이콘 · 커스텀 요소

이미지·아이콘을 링크 텍스트와 조합하거나, 실제 동작의 의미에 맞춰 button을 루트 요소로 사용할 수 있습니다.

아이콘 문서 프로필

색상

공통 color_* 클래스를 조합합니다. 버튼·배지·알림 등 다른 컴포넌트와 동일한 클래스명을 사용합니다.

Primary Muted Success Warning Danger

크기

공통 size_* 클래스로 텍스트 크기를 조절합니다.

Small Base Large Extra Large

스타일

link_underline · link_no-underline · link_standalone으로 밑줄과 터치 영역을 조절합니다.

기본 (hover 밑줄) 항상 밑줄 밑줄 없음 터치 영역 확대

내비게이션

link_nav · is-active로 메뉴·탭 링크를 표현합니다.

개요 컴포넌트 토큰 접근성
이전 페이지

블록 · 그룹

link_block · link_group으로 세로 링크 목록을 구성합니다.

시작하기 컴포넌트 도움말

아이콘 전용

link_icon-only으로 텍스트 없는 링크 버튼을 만듭니다.

아이콘

link_icon으로 텍스트 앞·뒤에 아이콘을 배치합니다. 장식용 아이콘은 aria-hidden="true"를 지정합니다.

외부 링크 다운로드 다음 단계

새 창 열기

target="_blank"과 rel="noopener noreferrer"를 함께 지정합니다. 스크린 리더용 안내 문구를 링크 텍스트에 포함합니다.

공식 문서 (새 창)

비활성

aria-disabled="true"와 tabindex="-1"로 비활성 링크를 표현합니다. 클릭 불가 시 href를 제거하거나 span으로 대체할 수 있습니다.

비활성 링크 비활성 (span)

문맥 속 사용

알림·카드·폼 등 다른 컴포넌트 안에서 보조 액션 링크로 활용합니다.

클래스 · 속성

Nuxt와 Next 컴포넌트가 렌더하는 OOCSS 클래스와 접근성 속성입니다. HTML에서는 이동에는 a, 현재 문맥의 동작에는 button을 사용해 아래 항목을 조합합니다.

클래스 · 속성 설명
link독립 액션·내비게이션 링크 루트
link_underline · link_no-underline · link_standalone밑줄·터치 영역 변형
link_nav · link_back · link_block · link_icon-only용도별 변형
link_icon · link_media링크 내부 아이콘·이미지
link_row · link_group · link_group-inline링크 묶음 레이아웃
is-active · is-disabled활성·비활성 상태
color_* · size_*공통 색상·크기 유틸리티
href이동 목적지. 페이지·리소스 이동이 아닌 동작에는 button 사용
aria-current="page"현재 페이지를 가리키는 내비게이션 링크
aria-label아이콘 전용 링크의 접근 가능한 이름
aria-disabled="true" · tabindex="-1"비활성 링크 상태와 Tab 순서 제외
target="_blank" · rel="noopener noreferrer"새 창 링크의 보안 속성. 링크 텍스트에도 새 창 안내 제공
data-ripple클릭 파장 활성
data-ripple="false" · data-no-ripple해당 요소 또는 하위 전체 클릭 파장 비활성
