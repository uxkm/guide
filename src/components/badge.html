클래스 · 속성

Nuxt와 Next 컴포넌트가 렌더하는 OOCSS 클래스와 접근성 속성입니다. HTML에서는 콘텐츠 의미에 맞는 요소에 아래 항목을 직접 조합합니다.

클래스 · 속성 설명
badge텍스트 배지 루트
badge_sm · badge_lg크기 변형. 기본은 md
badge_dot텍스트 앞에 상태 점 표시
badge_count숫자·짧은 텍스트용 카운트 형태
badge_dot-only텍스트 없이 상태 점만 표시
badge_wrap기준 요소 위에 카운트·상태 점을 겹치는 컨테이너
color_*배경·텍스트·상태 점의 공통 색상 유틸리티
role="status" · aria-label단독 상태 점에 상태 의미와 접근 가능한 이름 제공
aria-label시각적 값보다 구체적인 설명이 필요한 카운트 배지에 사용
