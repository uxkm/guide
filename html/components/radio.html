Radio

단일 선택을 위한 Radio 컴포넌트입니다. 기본 너비는 인라인(콘텐츠)이며, radio_block · radio_group_block으로 전체 너비를 사용합니다.

유형

기본은 span.radio_control + label.radio_label for(명시 연결) 순서입니다. 보이는 레이블이 없으면 label.radio_control로 input을 암묵 연결합니다. radio_label-end는 레이블 → 라디오 순서이며, 기본 너비는 콘텐츠 기준입니다.

<!-- 예시 1 -->

<div class="radio">
  <span class="radio_control">
    <input id="radio-auto-0" type="radio" class="radio_input" name="radio-type-basic" checked>
    <span class="radio_box" aria-hidden="true">
    </span>
  </span>
  <label class="radio_label" for="radio-auto-0">기본 — radio</label>
</div>

<!-- 예시 2 -->

<div class="radio radio_label-end">
  <label class="radio_label" for="radio-auto-1">레이블 뒤 — radio_label-end</label>

    <input id="radio-auto-1" type="radio" class="radio_input" name="radio-type-label-end">
    <span class="radio_box" aria-hidden="true">
    </span>
  </span>
</div>

단독 사용

레이블 없이 라디오만 사용할 수 있습니다. aria-label로 접근 가능한 이름을 지정합니다.

<div class="radio_group radio_group_horizontal">
  <label class="radio_control" data-ripple>
    <input aria-label="항목 선택" type="radio" class="radio_input" name="radio-standalone">
    <span class="radio_box" aria-hidden="true">
    </span>
  </label>
  <label class="radio_control" data-ripple>
    <input type="radio" class="radio_input" name="radio-standalone" checked aria-label="선택됨">
    <span class="radio_box" aria-hidden="true">

</div>

클래스 · 속성

Nuxt와 Next 컴포넌트가 렌더하는 OOCSS 클래스와 네이티브 라디오 속성입니다. HTML에서는 그룹, 레이아웃과 상태에 맞게 직접 조합합니다.

클래스 · 속성 설명
radio레이블이 있는 라디오 루트
radio_control · radio_input · radio_box네이티브 입력과 커스텀 선택 원을 묶는 구조
radio_label · radio_content · radio_hint레이블, 복합 레이블 콘텐츠, 보조 설명
radio_sm · radio_lg작은·큰 크기 변형. 기본은 md
radio_block · radio_group_block단일 라디오와 그룹의 부모 너비 100% 변형
radio_label-end · radio_button레이블을 앞에 배치하는 변형과 버튼형 선택
radio_group · radio_group_horizontal · radio_group_compact세로·가로·조밀한 라디오 그룹
radio_group-legendfieldset 그룹의 범례
radio_card · radio_card-clickable카드형 조합. clickable은 카드 전체 클릭을 JS로 위임
color_primary · color_success · color_danger · color_warning선택 상태와 버튼·카드형 색상 변형
is-checked · is-disabled · is-errorCSS·JS 상태 클래스
type="radio" · checked · disabled입력 유형과 네이티브 선택·비활성 상태
name · value동일 그룹 연결과 제출 값을 지정하는 네이티브 속성
id · for네이티브 입력과 보이는 레이블의 명시적 연결
aria-label · aria-labelledby단독 라디오, 그룹과 카드형 라디오에 접근 가능한 이름 제공
data-ripple단독·버튼형·클릭 가능한 카드의 클릭 파장 활성
data-ripple="false" · data-no-ripple해당 요소 또는 하위 전체의 클릭 파장 비활성
change선택 상태 변경을 처리하는 네이티브 이벤트
