Snackbar

작업 결과나 짧은 상태 변화를 화면 흐름을 방해하지 않고 일시적으로 전달하는 피드백 컴포넌트입니다.

기본

info · success · warning · error 의미 색상으로 짧은 피드백을 전달합니다.

변경 사항이 저장되었습니다. 
<div class="snackbar_region snackbar_region_static" aria-label="알림">
  <div class="snackbar color_info snackbar_motion-none is-open" role="status" aria-live="polite">
    <span class="snackbar_message">변경 사항이 저장되었습니다.</span>
  </div>
</div>

아이콘이름사용

alert-triangle경고

접근성

Snackbar는 포커스를 강제로 이동하지 않고 라이브 영역으로 상태 변화를 전달합니다.

  • 일반적인 작업 결과는 role="status"와 aria-live="polite"를 사용하고, 즉시 확인해야 하는 오류에만 role="alert"를 사용합니다.
  • aria-atomic="true"로 메시지 전체를 알리고 aria-relevant="additions text"로 추가·변경된 내용을 전달합니다.
  • 자동 닫기를 사용할 때는 내용을 읽고 액션을 수행할 충분한 시간을 제공하며, 호버 또는 내부 포커스 중에는 남은 시간을 일시정지합니다.
  • 닫기 가능한 Snackbar 내부에 포커스가 있을 때 Esc로 닫을 수 있습니다. 표시될 때 사용자 포커스를 Snackbar로 강제 이동하지 않습니다.
  • 상태 아이콘은 aria-hidden="true"로 숨깁니다. 색상이나 아이콘에만 의존하지 않고 메시지 텍스트로 상태를 설명합니다.
  • 액션은 하나의 짧고 명확한 동작으로 제공하고, 아이콘 전용 닫기 버튼에는 aria-label="알림 닫기"를 지정합니다.
  • 운영체제에서 모션 감소를 설정하면 Fade·Slide 시간을 최소화합니다.
